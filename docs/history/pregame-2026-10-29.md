## Reproduce preparation

The acquisition/build command used was:

```sh
rink-lab.venv/bin/python scripts/issue_daily_forecasts.py \
  --date 2026-10-29 \
  --template-forecast data/processed/forecasts/per_game_20262027_20261009T195052Z
```

This command always creates a new source/forecast vintage; it does not overwrite the morning release. Run only while the entire slate is at least ten minutes away. A later status-only report can use `build_today_report.py --espn-snapshot PATH` with the frozen bundle to preserve its model means and original injury timestamp.

Kalshi acquisition used `snapshot_kalshi_hockey.py --series KXNHLGAME KXNHLTOTAL KXNHLTEAMTOTAL KXNHLSAVES KXNHLSAVE KXNHLAST KXNHLPTS KXNHLANYGOAL KXNHLGOAL`. The raw snapshot path and hashes are in `data/processed/forecasts/hockey_20261029T140409985231Z/manifest.json`. `map_kalshi_winner_benchmark.py` mapped that same snapshot once for each probability release. `snapshot_kalshi_liquidity.py --benchmark ... --out NEW_DIRECTORY` preserves all public depth and trade pages separately. Contract rules, date, both official teams and game starts are checked before mapping.

`issue_frozen_feature_trial.py` used the October 20 evidence release and today's official actuals, defense PBP and MoneyPuck shots. `publish_pregame_data_use.py` combines the frozen bundle, team-model, original-probabilities, benchmark, liquidity, features and fantasy report; every argument accepts an explicit path and `--out` must be new. Input paths/timestamps are exported in the source registry. No raw data was manually edited.
