## Model lineage

The historical player-rate selection comes from the validated season artifact built November 6 (`per_game_20262027_20261106T213320Z`). The daily builder uses its selected historical validation parameters and prior-season player panel, drops its current-season rows, and recomputes current-season production from cutoff-safe official game history through November 8. This season artifact is a required input to the daily build; it does not replace the weekend daily challengers.

The issued player bundle uses `daily_usage_context_v2_opportunity_challengers` from the current daily configuration. Calibrated-opponent SOG remains the selected model for the all-player shots view based on the earlier paired evaluation. Fantasy category shots keep their separate default policy. The weekend `usage_toi_only_trial` and `pp_opportunity_trial` are present for comparison and remain unpromoted.

Direct team goals and winner probabilities use `team_goal_context_v2`, fitted through October 26, with lagged features through November 8. The November 8 probability calibrator is saved separately as a challenger; raw probabilities remain selected. These game forecasts do not use Kalshi prices. MoneyPuck xG context enters only the separate direct team-goal model under its existing data-quality checks.

## Reproducibility

The public frozen release preserves player, team and goalie rows, issue timing, model variants, source vintage and file hashes. Private ESPN player IDs, fantasy ownership, raw API snapshots and credentials are excluded from the public export. Local source snapshots remain available for rebuilding the issue.
