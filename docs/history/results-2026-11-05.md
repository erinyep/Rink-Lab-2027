# Model results — November 5, 2026

The saved 11-game pregame forecast was scored against refreshed official NHL results and player statistics. The evaluation covered **395 participating player rows**; one actual participant was not modeled, and nonparticipants were not assigned zero conditional production.

| Measure | Result |
| --- | ---: |

| Default SOG MAE | 1.022 |
| Usage-trial SOG MAE | 1.018 |
| Usage-trial conditional TOI MAE | 2.177 minutes |

| Default team-shots MAE | 3.646 per team |

Across the November 4–5 saved slates, calibrated-opponent SOG MAE was **1.007** versus **1.018** for default across 538 player-games. The usage result remains mixed by role, and the default team-shot model beat the shot-context variants on November 5. Goalie context slightly lowered goals-against MAE but worsened shots-against and saves MAE.

These recent samples do not warrant refitting or expanding a promotion. Keep the existing calibrated-opponent model selected for all-player NHL SOG, retain separate fantasy category policies, and continue collecting prospective results. Full scored rows, metrics, coverage and source hashes are in the [November 5 results package](../../outputs/per_game_forecast/results_2026-11-05/README.md); the [two-date role breakdown](../../outputs/per_game_forecast/results_2026-11-05/two_date_shots_metrics.csv) is exploratory.
