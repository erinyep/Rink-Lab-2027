# Daily forecast model template

Prepared from the validated forecast inputs dated 2026-11-18. Contains the historical player-season panel and model-selection metadata needed to issue daily forecasts. NHL current-season rows are excluded by the issuer before the new date is rebuilt.

The source manifest records the NHL public API acquisitions, validation settings, and code hashes used for this model snapshot. This compact artifact is an issuance input; it is not a new model fit.
