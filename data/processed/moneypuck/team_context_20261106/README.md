# MoneyPuck team-game context

This compact release retains the original source columns for regular-season Team Level rows from 2022-23 through 2026-27, across all five published situations. It is suitable for the current direct team-goal and lagged 5-on-5 shot-context workflows. The full upstream download is much larger; this file is a documented row-filtered subset.

MoneyPuck source: [published team-game data](https://moneypuck.com/data.htm). Non-commercial research use; please credit MoneyPuck.com. The source retrieval time, original file hash, filters, row counts, and published file hash are in `metadata.json`.

Coverage ends on the per-season dates in the manifest. MoneyPuck may revise historical values in later downloads; this is the frozen November 6, 2026 vintage, not a historical as-of series.
